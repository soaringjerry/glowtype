# Analytics 数据问题排查指南

## 已知问题

### 1. 维度样本量不一致

**现象**：不同维度的样本量 N 不同

**原因**：某些 `quiz_results` 记录的 `dimension_scores` 字段缺少部分维度。

**排查方法**：
1. 在 Analytics 页面点击「群组对比」面板的 🐛 按钮查看调试信息
2. 查看「缺少维度的记录」列表

**可能的根本原因**：
- 问卷配置变更：新增/删除了维度，历史数据与当前配置不匹配
- 题目选项配置错误：某些选项的 `scores` 字段没有包含所有维度
- 数据迁移问题

---

### 2. 分半信度 (SB) 全部为 0.000

**现象**：所有维度的 Spearman-Brown 分半信度都显示 0.000

**原因**：分半信度要求每个题目都有完整的 N 个响应。当有效题目数 < 2 时返回 0。

**排查方法**：
- 查看信度面板中的 `⚠️ Q: x/y` 标记
- `x` 是有完整响应的题目数，`y` 是总题目数
- 如果 `x < 2`，分半信度无法计算

---

### 3. 群组对比缺少某些维度

**现象**：按语言/设备分组对比时，某些维度不显示

**原因**：每个组需要至少 10 个样本。如果某维度在某组样本数 < 10，该组被排除。剩余组数 < 2 时整个维度不显示。

**排查方法**：
1. 点击 🐛 按钮查看调试信息
2. 查看「每个语言组的维度样本数」表格
3. 红色数字表示低于阈值

---

## 数据验证 SQL

### 查找 dimension_scores 不完整的记录

```sql
-- 统计每条记录有多少个维度
SELECT
  id,
  created_at,
  json_array_length(json_keys(dimension_scores)) as dim_count
FROM quiz_results
ORDER BY dim_count ASC
LIMIT 20;
```

### 检查最近数据是否完整

```sql
SELECT id, created_at, dimension_scores
FROM quiz_results
ORDER BY created_at DESC
LIMIT 10;
```

## 调试工具

### Analytics 页面调试功能

1. **群组对比调试面板** (🐛 按钮)
   - 总记录数 & JSON 解析错误数
   - 按语言/设备统计
   - 维度样本数表格
   - 缺少维度的记录列表

2. **信度面板诊断**
   - `⚠️ Q: x/y` 显示有效题目数
   - 黄色背景表示数据不完整

### 强制刷新缓存

点击刷新按钮强制重新计算，绕过缓存。
